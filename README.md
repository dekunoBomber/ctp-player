# ctp-player

CITIZEN TAX PLANNER（Star Citizen 向けの Chrome 拡張機能）の BGM 用の、小さな中継の頁です。

- 拡張機能の頁は Web のサイトではないため、YouTube の埋め込みが再生できません（エラー 153）。この頁が YouTube の公式の埋め込みを出し、拡張機能からは「再生・止める・音量・曲の並び」だけを受け取ります。
- 流すのは、YouTube で公開されている動画を、YouTube の公式の埋め込みで流すだけです。曲のファイルは置いていません。
- データは何も集めません。
